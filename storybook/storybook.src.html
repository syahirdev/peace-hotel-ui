Rules

Follow these and nothing can drift out of sync again. tools/check-design.js runs on every pull request and fails when a rule is broken.

  • Raw values live in one placeEvery colour, corner, font and font size is a --pu-* token at the top of nitro.css. The Peace UI panels read the same tokens.
  • One look per jobMain action = primary (blue). Delete, report, the profile X = danger (red). Everything else = default (dark two-tone).
  • One heightButtons, chips, inputs, selects and square icon buttons are 36px (--pu-ctl). Only bottom action bars use 44px.
  • One corner6px (--pu-r) on everything you can tap or read in a box. 4px only for parts inside a padded control.
  • One XEvery close button is the same 36px square with the same drawing (--pu-i-x), in Nitro windows and Peace panels.
  • Pages set layout onlyA window's own section in nitro.css may set size, position, order and gaps. A new look means adding the element to a component list.

Colour

Near-black surfaces in steps, light text in three strengths, and three accents with a job each. Duotone fills are Peace's HUD look: the top half a shade lighter.

Type

Ubuntu for text, Ubuntu Bold for titles, names and primary buttons. Seven sizes.
